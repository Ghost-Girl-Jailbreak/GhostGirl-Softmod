# GhostGirlRepack

This folder is a placeholder.

The actual softmod files are **not** committed to the repo. They
are attached to GitHub Releases as `GhostGirlRepack.zip`.

To work with the softmod package:

1. Download `GhostGirlRepack.zip` from the
   [Releases page](../../releases).
2. Extract it locally on your PC.
3. Copy the **files inside** the folder to a FAT32 USB stick.

See [docs/INSTALL.md](../docs/INSTALL.md) for the full walkthrough.

---

## Why This Folder Exists

Git doesn't track empty folders. This README keeps the folder
present in the repo so the structure is clear to anyone browsing.

**Do not commit softmod files here.**
