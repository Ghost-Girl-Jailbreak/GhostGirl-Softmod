## ✨ About

</div>

**GhostGirl Softmod** is the jailbreak package for Xbox 360 consoles — the `GhostGirlRepack.zip` file that gets you set up to run homebrew apps.

Part of [Project Ghost Girl](https://github.com/Ghost-Girl-Jailbreak/Project-Ghost-Girl-).

<div align="center">

| Feature | Description |
|:---|:---|
| 🔓 **Softmod Package** | Everything you need in one zip |
| 💾 **USB-Based** | No hardware modifications required |
| ⚡ **Temporary Jailbreak** | Safer than permanent softmod |
| 🎮 **ABadUpdate / ABadAvatar** | Works on both exploits |
| 🚫 **No Telemetry** | Runs entirely offline |

</div>

> ⚠️ **Requires a jailbreakable Xbox 360.** See [Compatibility](#-compatibility) below.

## ⚠️ READ FIRST

</div>

**Before you do anything else, read the full installation guide.**

The softmod will **not** work if you skip the setup steps — especially:

- Turning **Wi-Fi off**
- Turning **Auto Sign-In off**
- Using the **correct USB port**
- Waiting the **correct time** before powering on

📖 **Full Install Guide →** [docs/INSTALL.md](docs/INSTALL.md)

If you install it manually without following the guide, the exploit will fail and you'll think the package is broken. It isn't — you just missed a step.

## 🚀 Quick Start

</div>

> 📖 **This is a summary only.** Follow the [full install guide](docs/INSTALL.md) for the exact steps.

1.  Download **`GhostGirlRepack.zip`** from Releases.
2.  Extract the zip on your PC.
3.  Open the folder named **`GhostGirlRepack`**.
4.  Format a USB stick to **FAT32**.
5.  Copy **all files and folders inside** `GhostGirlRepack` to the **root** of the USB stick.
    - ⚠️ Do **not** copy the folder itself — only its contents.
6.  On your console: turn **Wi-Fi off** and **Auto Sign-In off**.
7.  Power the console off and wait **30 seconds**.
8.  Insert the USB stick into the port **closest to the power button**.
9.  Wait **5 seconds**, then press the power button.
10. Wait for the **`abadavatar`** profile to appear, then click it to sign in.

Full guide → [docs/INSTALL.md](docs/INSTALL.md)

## ⚠️ Warning

</div>

### Permanent Softmod — NOT Recommended

**GhostGirlRepack can permanently soft-mod your console.** However, this is **NOT recommended at the moment.**

**Why not?**

- The permanent method is still **in testing**
- Recovery from a bad flash may require **hardware tools**
- Temporary softmod (USB-based) is **safer** and **reversible**

**Use the temporary USB method for now.**

Permanent softmod will only be recommended once it's been verified stable on **Trinity**, **Corona**, and **Winchester** console revisions.

### Modding Risk

- Modding voids warranties
- Carries risk of bricking the console
- May be illegal in some jurisdictions

See the [Project Ghost Girl Disclaimer](https://github.com/Ghost-Girl-Jailbreak/Project-Ghost-Girl/blob/main/DISCLAIMER.md).
